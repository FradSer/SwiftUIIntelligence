# SwiftUI capability coverage

SwiftUIIntelligence is a constrained native UI vocabulary for generated documents, not the entire SwiftUI API. Package minimum: iOS/iPadOS 26 and macOS 26, Swift 6.2. This round compiled using Xcode 27.0 (27A266a); visual tests use iOS 27 simulators. Availability is based on installed SDK declarations, not a promise that every current web documentation API runs on OS 26. No OS 27-only API is used by the package. OS 26 runtime visual testing is not available on this Mac.

The authoritative supported kinds are `ComponentCatalog.components` (`UINode.Kind.allCases`); a test checks schema variants against the catalog and the renderer switch is exhaustive. The model uses a smaller general grammar for a bounded request; this is capability selection, not a domain-specific screen or topic-to-fixture router.

| Apple capability family | SDK status | SwiftUIIntelligence scope / limits | Official source |
|---|---|---|---|
| Text, SF Symbols, stack, grid, section, list | Previously supported | Semantic symbol allowlist; vertical/fit layouts; bounded plain content | [SwiftUI](https://developer.apple.com/documentation/swiftui), [layout](https://developer.apple.com/documentation/swiftui/view-layout) |
| Tables / comparison | Previously supported; compact fallback this round | Rectangular 1–6 columns, 1–32 rows; semantic labeled rows when Grid does not fit. No sorting/filtering language, native Table selection or large datasets | [Table](https://developer.apple.com/documentation/swiftui/table) |
| Metrics, badges, progress | Previously supported | Validated values; supplied numeric aggregate, no model arithmetic | [controls](https://developer.apple.com/documentation/swiftui/controls-and-indicators) |
| Charts | Previously supported | Swift Charts line/area/bar/donut; bounded labels/series. Radar is a custom library renderer, not a native Charts mark | [Charts](https://developer.apple.com/documentation/charts) |
| Editable form/section | Implemented this round | Form schema renders vertically arranged native controls with section semantics. It does not embed a second scrolling SwiftUI Form in the document ScrollView | [Form](https://developer.apple.com/documentation/swiftui/form) |
| TextField/TextEditor/Toggle/Picker/Slider/Stepper/DatePicker | Implemented this round | Typed bindings, choices, finite ranges, ISO8601 instants; host-owned edits survive navigation/revision. Native typed-envelope generation covers one field per selected control type; repeated types remain unverified. No SecureField or sensitive data flow | [controls](https://developer.apple.com/documentation/swiftui/controls-and-indicators) |
| Navigation | Implemented this round | Existing section ID destinations; no cycles/nested links. Host provides NavigationStack. Native generation grammar currently bounds a request to one first-level route; renderer can resolve multiple independent destinations | [navigation](https://developer.apple.com/documentation/swiftui/navigation) |
| Timeline / plan | Implemented this round | Ordered supplied time/title/detail events using native text/layout. No calendar scheduling, reminders or Date arithmetic; not TimelineView background refresh | [TimelineView](https://developer.apple.com/documentation/swiftui/timelineview) |
| Local set/select | Implemented this round | Native control bindings and bounded state setter. No generated expressions; filter/sort/computed-state DSL not supported | [model data](https://developer.apple.com/documentation/swiftui/model-data) |
| Host actions | Host authorization required | Register exact callback IDs; async typed state snapshot + unique event ID; in-flight UI guard and result/error. Generation never executes actions. Host owns persistence, deduplication, network/permission decisions | [Button](https://developer.apple.com/documentation/swiftui/button) |
| Liquid Glass | OS 26 supported; SwiftUI automatic presentation | Native controls/navigation use OS automatic appearance. Custom content cards use default regular glassEffect and default GlassEffectContainer grouping, with ConcentricRectangle corners (20pt library minimum, not a universal Apple default). No buttonStyle override, tint, rim, lining, added border or shadow. Native Form/Section presents standalone interactive documents. Semantic layouts/data colors remain. No promise of web pixel parity or visionOS compatibility | [custom glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views), [HIG materials](https://developer.apple.com/design/human-interface-guidelines/materials) |
| Accessibility | Partial | Native controls, accessible labels, system fonts/Dynamic Type, adaptive rows; no new animations. System glass controls follow system settings. Tested coverage is in validation matrix; VoiceOver/RTL/full Reduce Motion/Transparency device setting combinations remain unverified | [accessibility](https://developer.apple.com/documentation/swiftui/accessibility-fundamentals) |
| Apple Foundation Models | OS 26 supported; this round streaming/retries | SystemLanguageModel availability, DynamicGenerationSchema, finite identifier enums (pattern API exists in OS26 SDK but this model runtime rejects it), cumulative snapshots, strict final decode+semantics, bounded retries. Streaming progress is observable; partial documents never render | [guided generation](https://developer.apple.com/documentation/foundationmodels/generating-swift-data-structures-with-guided-generation), [WWDC 286](https://developer.apple.com/videos/play/wwdc2025/286/) |
| HTTP / existing chatbot | Previously supported | Host-configured provider/closure; same final validation. No automatic cloud fallback, endpoint or credential added | [URLSession](https://developer.apple.com/documentation/foundation/urlsession) |
| Images/assets/AsyncImage | Not supported | Future approved asset resolver required; generated arbitrary remote URLs are not executed. Current beta request customization not adopted | [AsyncImage](https://developer.apple.com/documentation/swiftui/asyncimage) |
| Maps/location, photos/camera, media/AVKit, file import/export, calendar/contacts, notifications, payment | Not supported; future host authorization required | No generated permission requests or access. No entitlements/network/privacy permissions added | [MapKit](https://developer.apple.com/documentation/mapkit), [PhotosUI](https://developer.apple.com/documentation/photosui), [AVKit](https://developer.apple.com/documentation/avkit) |
| Sheets, alerts, tabs, split navigation, gestures, custom animation/shaders, drag/drop, 3D/RealityKit, widgets, app intents | Not supported | These SwiftUI families are outside the current JSON vocabulary; no arbitrary Swift execution | [SwiftUI](https://developer.apple.com/documentation/swiftui) |

Safety boundary: ≤64 KiB, 128 nodes, depth 12, 32 children/layout, 32 state fields, 32 chart points, unique IDs, known component enums, field allowlists, rectangular rows, finite ranges and valid binding/destination/action references. Arbitrary Swift, JS, selectors, reflection, paths, URL actions and expressions are not accepted.
